MTM DIGITAL | راهنمای نصب نسخه متصل به PHP
==========================================

پیش‌نیازها
- PHP نسخه 8.0 یا بالاتر
- Apache با mod_rewrite و اجازه استفاده از .htaccess
- افزونه fileinfo برای آپلود امن تصویر
- افزونه cURL برای اتصال واقعی به زرین‌پال (در حالت mock لازم نیست)
- دسترسی نوشتن برای پوشه‌های data و uploads

نصب اول
1) فایل ZIP را استخراج کنید.
2) محتویات پوشه mtm_digital_site_amir را مستقیماً داخل public_html دامنه قرار دهید.
3) مطمئن شوید فایل index.html و پوشه api در ریشه public_html هستند.
4) مجوز پوشه‌های data و uploads را معمولاً روی 775 تنظیم کنید؛ از 777 استفاده نکنید.
5) آدرس https://دامنه-شما/api/health را باز کنید. وضعیت writable باید برای data و uploads درست باشد.
6) با حساب مدیر وارد شوید و بلافاصله رمز پیش‌فرض را عوض کنید. نمونه درخواست تغییر رمز در ادامه آمده است.

ورود مدیر اولیه
ایمیل: admin@mtmdigital.ir
رمز عبور: admin123456
این رمز فقط برای نصب تازه است. پس از ورود، آن را تغییر دهید و اطلاعات دسترسی را در اختیار دیگران نگذارید.

تغییر رمز مدیر (پس از ورود و با همان نشست مرورگر):
در کنسول مرورگر این کد را اجرا کنید و مقادیر رمز را جایگزین کنید:
fetch("/api/auth", { method: "POST", credentials: "same-origin", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ action: "change_password", current_password: "admin123456", new_password: "یک-رمز-تصادفی-حداقل-۱۰-کاراکتری" }) }).then(r => r.json()).then(console.log);

اتصال پرداخت
- شبیه‌ساز داخلی فقط روی localhost یا در محیطی که متغیر سرور MTM_ALLOW_MOCK_PAYMENT=1 به‌صورت آگاهانه تنظیم شده باشد فعال است؛ این متغیر را روی سایت عمومی فعال نکنید. روی سرور عمومی برای استفاده واقعی، مرچنت‌آیدی معتبر زرین‌پال را از پنل مدیریت ثبت کنید.
- برای پرداخت واقعی، cURL باید روی هاست فعال باشد و آدرس بازگشت (Callback) روی دامنه HTTPS تنظیم شود.
- تا زمانی که اطلاعات درگاه واقعی ثبت و تأیید نشده، پرداخت واقعی فعال نخواهد شد.

نکات مهم
- اطلاعات کاربران، سفارش‌ها و تنظیمات در data ذخیره می‌شود. این پوشه با .htaccess محافظت شده است؛ آن را از هاست عمومی یا بکاپ خصوصی حذف نکنید.
- فایل‌های آپلودی در uploads ذخیره می‌شوند و اجرای فایل PHP از آن پوشه مسدود است.
- هنگام آپدیت، پوشه‌های data و uploads را حذف یا جایگزین نکنید.
- برای بررسی وضعیت سرور از /api/health استفاده کنید.
- مسیرهای فروشگاه و پنل مدیریت توسط React مدیریت می‌شوند و APIها از مسیر /api/... در همان دامنه در دسترس‌اند.
