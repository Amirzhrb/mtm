MTM DIGITAL | گزارش اتصال فرانت‌اند React به بک‌اند PHP
======================================================

وضعیت
- مسیر احراز هویت فرانت‌اند به نشست PHP متصل شده است؛ ورود، ثبت‌نام، بازیابی نشست و خروج از /api/auth استفاده می‌کنند.
- فراخوانی جایگزین Supabase در خطاهای احراز هویت حذف شده است تا نشست دوگانه ایجاد نشود.
- مسیرهای API از طریق /api/<name> به فایل‌های PHP متناظر هدایت می‌شوند.
- دسترسی‌های مدیریتی، سفارش‌ها، تنظیمات حساس، آپلود و عملیات حذف/ویرایش سمت سرور کنترل می‌شوند.
- محاسبه قیمت نهایی سفارش، تخفیف، هزینه ارسال و کنترل موجودی در PHP انجام می‌شود؛ مبلغ ارسالی مرورگر معتبر فرض نمی‌شود.
- callback پرداخت با authority ذخیره‌شده سفارش تطبیق داده می‌شود و پرداخت آزمایشی فقط در محیط محلی قابل استفاده است.
- فایل‌های داده از دسترسی مستقیم وب محافظت شده‌اند و اجرای فایل PHP در پوشه uploads مسدود شده است.
- برای جلوگیری از کش نسخه قبلی، فایل‌های JS تغییر یافته با نام‌های جدید نسخه‌بندی شده‌اند.
- endpoint سلامت سرور در /api/health قرار دارد.

- بررسی نحوی ۳۶ فایل JavaScript با node --check: موفق.
- بررسی مسیر فایل‌های استاتیک: هیچ reference مفقودی پیدا نشد.
- درخواست HTTP به صفحه اصلی، endpoint سلامت، bundleهای اصلی و مسیر React: پاسخ ۲۰۰.
- ورود مدیر، نشست PHP، خروج و کنترل نقش‌ها: موفق.
- ایجاد محصول و سفارش، محاسبه قیمت از دیتابیس JSON و کاهش موجودی: موفق.
- ایجاد پرداخت آزمایشی، رد authority اشتباه، تأیید authority صحیح و callback تکراری: موفق.
- آپلود و اعتبارسنجی تصویر و محدودیت دسترسی کاربر عادی: موفق.
- تغییر رمز عبور از طریق action=change_password در /api/auth: موفق.

محدودیت‌های تست
- در محیط ساخت افزونه PHP cURL نصب نبود؛ بنابراین اتصال زنده به درگاه زرین‌پال و callback واقعی قابل آزمایش نبود. برای پرداخت واقعی، cURL و مرچنت‌آیدی معتبر روی هاست لازم است.
- افزونه mbstring در محیط ساخت نصب نبود؛ برای توابع مورد استفاده fallback در کد قرار داده شده است.
- تست خودکار رندر کامل در مرورگر headless در محیط ساخت به دلیل محدودیت اجرای مرورگر تکمیل نشد؛ تست‌های lint و HTTP/API انجام شده‌اند.
- رفتار نهایی هاست به نسخه PHP، Apache/mod_rewrite، مجوز پوشه‌ها، HTTPS و پیکربندی درگاه وابسته است.

نصب
راهنمای نصب و پرداخت در README-INSTALL.txt است. محتویات این بسته را در ریشه public_html استخراج کنید. پوشه‌های data و uploads را در به‌روزرسانی‌های بعدی حذف یا جایگزین نکنید.
