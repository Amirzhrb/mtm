========================================
آپدیت امن sitemtm.zip بدون پاک شدن محصولات
========================================

سایت شما روی هاست با فایل‌های JSON در پوشه data/ و عکس‌ها در uploads/
کار می‌کند. اگر کل زیپ را روی public_html بریزید و Replace All بزنید،
ممکن است data و uploads قدیمی شما پاک/جایگزین شود.

روش درست (پیشنهادی):
---------------------
1) از هاست بکاپ بگیرید:
   - کل public_html
   مخصوصاً پوشه‌های: data/  و  uploads/

2) زیپ جدید را Extract کنید.

3) فقط این‌ها را جایگزین کنید (Overwrite):
   - index.html
   - assets/          (کل پوشه)
   - api/             (کل پوشه PHP)
   - .htaccess
   - favicon.svg
   - robots.txt
   - images/          (اختیاری؛ تصاویر پیش‌فرض قالب)

4) این‌ها را حذف یا جایگزین نکنید:
   - data/            << محصولات، دسته‌ها، تنظیمات، سفارش‌ها
   - uploads/         << عکس‌های آپلود شده شما
   قانون ریشه .htaccess در نسخه جدید، data را می‌بندد و اجرای فایل PHP داخل uploads را مسدود می‌کند؛ بنابراین .htaccess ریشه را حتماً به‌روزرسانی کنید.

5) دسترسی پوشه‌ها:
   chmod 775 data uploads
   (یا 755 اگر 775 مجاز نیست)

6) کش مرورگر / لایت‌اسپید را یک‌بار پاک کنید. فایل‌های JavaScript نسخه جدید نام تازه دارند تا نسخه قدیمی کش‌شده اجرا نشود.

اگر اشتباهاً data را جایگزین کردید:
------------------------------------
از بکاپ، فقط پوشه data و uploads را برگردانید.

نکته درگاه:
-----------
پنل > تنظیمات > درگاه
- gateway: زرین‌پال
- merchant_id را وارد کنید
- cURL روی هاست باید فعال باشد.
- مرچنت‌آیدی معتبر را وارد کنید.
- برای واقعی: sandbox خاموش باشد.
- شبیه‌ساز داخلی فقط روی localhost قابل استفاده است و برای سایت عمومی پرداخت واقعی را جایگزین نمی‌کند.
- callback: /payment/verify

سئو «ام تی ام دیجیتال»:
-----------------------
1) دامنه خود را در Google Search Console ثبت کنید
2) sitemap: https://YOUR-DOMAIN/api/seo?type=sitemap
3) در تنظیمات سئو عنوان و توضیحات را با نام برند و دامنه خود ذخیره کنید
