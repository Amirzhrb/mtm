# MTM Digital

فروشگاه اینترنتی فارسی RTL برای محصولات دیجیتال و لوازم جانبی، همراه با رابط React و بک‌اند PHP 8.

## اجزای پروژه
- رابط فروشگاه و پنل مدیریت: React build شده در `assets/` و صفحه اصلی `index.html`
- API: فایل‌های PHP در `api/` با مسیرهای هم‌دامنه `/api/...`
- ذخیره‌سازی: فایل‌های JSON در `data/`
- فایل‌های تصویری آپلودشده: `uploads/`

## نصب
راهنمای کامل پیش‌نیازها، نصب و اتصال پرداخت در `README-INSTALL.txt` قرار دارد. پس از نصب، سلامت سرویس را از `/api/health` بررسی کنید.

## امنیت
- `data/` نباید از وب قابل خواندن باشد. تنظیمات محافظتی `.htaccess` را نگه دارید.
- پس از نصب تازه، رمز اولیه مدیر را فوراً تغییر دهید.
- برای پرداخت واقعی، مرچنت‌آیدی معتبر و افزونه cURL لازم است. شبیه‌ساز پرداخت صرفاً برای توسعه محلی در نظر گرفته شده است.
- `data/` و `uploads/` را هنگام به‌روزرسانی پاک نکنید.
